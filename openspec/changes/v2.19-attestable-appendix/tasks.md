# Tasks

Implementation checklist for v2.19 — Attestable AI Work Appendix.

## 0. Prerequisites

- [ ] 0.1 v2.16 shipped (security baseline + PyPI fix).
- [ ] 0.2 v2.17 shipped (correction records + locking).
- [ ] 0.3 v2.18 shipped (cache hardening).
- [ ] 0.4 At least one design partner agreed to be the first appendix
  issuer.

## 1. Cryptography foundation

- [ ] 1.1 Add `cryptography` and `jcs` to dependencies.
- [ ] 1.2 `appendix.py`: `generate_keypair()` writes Ed25519 keypair to
  `~/.halyard/keys/issuer.ed25519` (mode 0600) and `issuer.pub`.
- [ ] 1.3 `sign_document(unsigned_json, private_key) -> bytes`.
- [ ] 1.4 `verify_document(json_with_signature, public_key) -> bool`.
- [ ] 1.5 Tests: round-trip a document; tampered doc fails verification.
- [ ] 1.6 Tests: cross-verify against `pyca/cryptography` reference.

## 2. Data model

- [ ] 2.1 Define `Appendix` dataclass + `AppendixSession`,
  `AppendixIssuer`, `AppendixRecipient`, `AppendixSummary` sub-types.
- [ ] 2.2 `to_canonical_json()` — JCS-canonicalized bytes.
- [ ] 2.3 `from_json(text)` — parser with strict validation.
- [ ] 2.4 Unit tests: schema rejects unknown fields, requires required
  fields.

## 3. Privacy enforcement

- [ ] 3.1 `_hash_path(p)` → `sha256:<hex>`.
- [ ] 3.2 `_no_prompt_leak` validator runs on every string field.
- [ ] 3.3 Fuzz test: 1000 randomized sessions produce 0 occurrences of
  source-code or prompt-text patterns in the output.
- [ ] 3.4 Fuzz test: 0 occurrences of unhashed paths.

## 4. CLI surface

- [ ] 4.1 `halyard appendix init` — keypair generation with first-run
  guidance.
- [ ] 4.2 `halyard appendix create --client --project --period
  --recipient --output`.
- [ ] 4.3 `--bundle pdf` flag — render PDF via Jinja + weasyprint.
- [ ] 4.4 `halyard appendix verify <file>` — local verification.
- [ ] 4.5 `halyard appendix publish-key` — upload to halyard.dev/keys
  with consent prompt.
- [ ] 4.6 `halyard invoice --with-appendix` — bundle with existing
  invoice generation.

## 5. PDF render

- [ ] 5.1 Jinja template `templates/appendix.html.j2`.
- [ ] 5.2 weasyprint integration for HTML-to-PDF.
