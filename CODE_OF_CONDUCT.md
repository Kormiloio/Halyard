# Code of Conduct

Halyard adopts the **Contributor Covenant, version 2.1** as its code of
conduct. The full text is published at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

By participating in this project — opening issues, submitting pull
requests, joining discussions, or contributing in any other way — you
agree to abide by it.

## Reporting

If you experience or witness behavior that violates the Covenant,
please report it by opening an issue in this repository titled
**"CoC contact request"** (no details in the title or body). A
maintainer will follow up privately.

If you are not comfortable reporting through GitHub, mention that in
the issue and a maintainer will suggest an alternate channel.

## Enforcement

Maintainers will follow the enforcement guidelines outlined in section
2 of the Covenant (linked above) when reviewing reports. Consequences
range from a private warning to a permanent ban, calibrated to the
severity and pattern of the conduct.
